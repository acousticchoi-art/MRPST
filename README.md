### Recurring academic timetable
- Fixed weekly timetable slots are configured per academic term and department.
- Each slot stores weekday (Monday=1 through Sunday=7), period, start/end time, course, room, instructor, and topic.
- The timetable interface filters by term and department and presents a weekly view.
- Database validation prevents overlapping classes within a department and conflicts for the same room or instructor.
- Legacy dated class sessions remain stored for compatibility and are not automatically converted.
